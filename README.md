# bumperbot_ws

A ROS 2 (Jazzy) workspace for **Bumperbot**, a differential-drive mobile robot: URDF/Xacro model, Gazebo simulation, `ros2_control` drive setup, joystick teleoperation, and a from-scratch kinematics controller written in Python.

## Packages

| Package | What it contains |
| --- | --- |
| `bumperbot_description` | Robot model (Xacro/URDF), STL meshes, RViz config, and launch files for RViz (`display.launch.py`) and Gazebo (`gazebo.launch.py`). Includes the `ros2_control` hardware description. |
| `bumperbot_controller` | `diff_drive_controller` configuration, a custom `simple_controller` node, joystick teleop config, and launch files. |
| `bumperbot_msgs` | Custom interfaces (`AddTwoInts.srv`). |
| `bumperbot_py_examples` | `rclpy` practice nodes: publisher/subscriber, parameters, service client/server, TF kinematics, turtlesim kinematics. |
| `bumperbot_cpp_examples` | C++ (`rclcpp`) package scaffold. |

### Highlights

- **Custom differential-drive controller** (`simple_controller.py`): subscribes to `TwistStamped` velocity commands and converts linear/angular velocity into left/right wheel speeds using the differential-drive kinematic model (wheel radius 0.033 m, wheel separation 0.17 m, both configurable as ROS parameters).
- **Two controller modes**, selectable at launch: the custom controller, or the stock `ros2_control` `DiffDriveController` (with velocity/acceleration limits and odometry TF).
- **Joystick teleoperation** via `joy` + `joy_teleop`.

## Build

```bash
git clone https://github.com/DivyomSrivastava/bumperbot.git
cd bumperbot
rosdep install --from-paths src --ignore-src -r -y
colcon build
source install/setup.bash
```

## Run

```bash
# View the model in RViz
ros2 launch bumperbot_description display.launch.py

# Simulate in Gazebo
ros2 launch bumperbot_description gazebo.launch.py

# Start the controllers (custom controller by default)
ros2 launch bumperbot_controller controller.launch.py
# ...or use the stock DiffDriveController
ros2 launch bumperbot_controller controller.launch.py use_simple_controller:=False

# Drive with a joystick
ros2 launch bumperbot_controller joystick_teleop.launch.py
```
